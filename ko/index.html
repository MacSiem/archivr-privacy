개인정보처리방침 — Archivr

최종 업데이트: 2026-09-13 · 시행일: 2026-05-06

1. 당사 소개

Archivr는 ZIP, 7z, TAR, TAR.GZ 및 RAR 읽기를 기기에서 로컬로 처리합니다. 처리를 위해 파일이나 압축 비밀번호를 업로드하지 않습니다. 사용자가 내보내기, 공유 또는 지원팀 전송을 선택하면 데이터가 기기 밖으로 나갈 수 있습니다. 비밀번호는 메모리에서 일시적으로 사용하며 설정이나 작업 기록에 저장하지 않습니다.

데이터 컨트롤러: Maciej Siemiński — Archivr 개발자 연락처: mail@macsiem.dev

Google Play를 통해 배포되는 앱 버전에 대한 데이터 컨트롤러는 LICENCEPRO POLSKA Sp. z o.o., ul. Huculska 6, 00-730 Warszawa, Polska입니다.

본 개인정보처리방침은 Archivr가 어떤 개인 데이터를 어떻게, 왜 처리하는지, 그리고 사용자에게 어떤 권리가 있는지 설명합니다.

2. 간략 요약

압축 파일은 기기에서 처리합니다. Unity Ads는 광고 데이터, Sentry는 기술 진단, Apple / Google은 구매 데이터를 처리합니다. Cloudflare는 앱 공지를 제공하며, 활성화된 푸시 알림에는 Expo와 Apple / Google 알림 서비스도 사용합니다. 수신자, 보관 기간과 권리는 아래에 설명합니다.

3. 당사가 처리하는 데이터

기기에는 환경설정, 시작 안내 완료 상태, Premium 등급과 만료일, 최대 50개 작업의 파일명·형식·크기·날짜·비밀번호 사용 여부가 저장됩니다. 기록에는 비밀번호나 파일 내용이 없으며 기록 화면에서 삭제할 수 있습니다. 기록 데이터베이스는 업로드하지 않습니다. 언어와 Premium 상태는 아래 공지 기능을 위해서도 전송합니다. 별도의 설치 인증 정보는 운영체제의 보안 저장소에 보관합니다.

Sentry는 오류 스택, 기기 모델, OS, 언어와 앱 버전을 처리합니다. Archivr는 파일 경로, 비밀번호 필드와 자유 형식 진단 메시지를 필터링하고 압축 파일 내용을 첨부하지 않습니다. 그러나 기술 메타데이터에는 기기 식별자가 포함될 수 있으므로 익명 데이터는 아닙니다. 보관 기간은 Sentry 프로젝트 설정에 따릅니다.

Unity Ads는 기기·SDK 식별자와 허용된 광고 ID, 국가 수준 위치, 구매 경향, 앱·광고 상호작용, 사용 신호와 기술 속성을 처리합니다. 목적은 광고 제공·측정, 분석, 서비스 운영과 남용 방지입니다. 필요한 동의를 받으면 개인화와 측정을 위해 서비스 간 데이터를 연결할 수 있습니다. 제한된 광고가 모든 기술 처리를 중단하는 것은 아닙니다. Lifetime은 광고를 영구 제거하고 연간 구독은 권한이 유효한 동안 제거합니다.

Apple / Google이 결제를 처리합니다. Archivr는 카드 정보를 요구하지 않으며 스토어가 반환한 구매 정보로 권한을 확인합니다. 구매 복원은 기존 권한을 다시 조회합니다. 상품은 Lifetime, 연간 구독과 선택적 팁입니다.

시스템 파일 선택기는 선택한 파일이나 폴더 접근을 허용하는 것이며 업로드 요청이 아닙니다. 활성화된 알림은 앱 공지를 전달할 수 있습니다. iOS 추적은 ATT로 관리하며 햅틱은 끌 수 있습니다. 연락처, 마이크와 정확한 위치 접근을 요청하지 않습니다.

지원 이메일을 보내면 발신 주소, 메시지와 미리보기에 표시된 기술 정보(설치 식별자 포함)를 받아 답변과 조사에 사용하며 광고에는 사용하지 않습니다. 연락처 화면을 열거나 주소를 복사하는 것만으로 이메일이 발송되지는 않습니다. 계정이 필요하지 않으며 전화번호, 우편 주소, 연락처 목록, 일정, SMS, 통화 기록, 앱 외부 방문 기록, 생체 또는 건강 정보를 요청하지 않습니다.

4. 데이터를 처리하는 이유 (목적)

  • 기기에서 앱 실행 — 로컬 저장소와 (존재하는 경우) 암호화를 통해 세션 간에 데이터가 유지됩니다.
  • 안정성 향상 — Sentry 진단은 사용자 사용에 영향을 미치는 충돌을 수정하는 데 도움이 됩니다.
  • 무료 서비스 유지 — Unity Ads은 프리미엄을 구매하지 않는 사용자에게 자금을 조달하기 위해 비침해적 광고를 제공합니다.
  • 구매 처리 — Apple/Google 결제 시스템은 사용자가 구매하기로 선택한 프리미엄 권한을 이행합니다.
  • 공지와 지원 제공: 기술적 설치 데이터로 앱 내 공지, 선택적 푸시 알림과 지원 요청 답변을 제공합니다.

5. 법적 근거 (GDPR Art. 6)

유럽 경제 지역, 영국, 스위스 사용자의 경우:

  • 계약 이행 (Art. 6(1)(b)) — 앱 실행, 구매 처리.
  • 정당한 이익(GDPR 제6조 제1항 f): 안정성 진단, 공지, 지원, 남용 방지와 비개인화 광고이며, 법률상 별도 동의가 필요한 경우 이를 받습니다. 신뢰성과 서비스 재원 확보의 이익이 사용자의 기본권보다 우선하지 않습니다.
  • 동의 (Art. 6(1)(a)) — 사용자가 ATT 동의 요청(iOS) 또는 인앱 환경설정을 통해 동의를 부여한 경우의 개인 맞춤 광고. 사용자는 이전 처리에 영향을 미치지 않고 언제든지 동의를 철회할 수 있습니다.
  • 법적 의무 (Art. 6(1)(c)) — 당국으로부터의 합법적인 요청에 응답해야 하는 경우에만 해당됩니다.

6. 수신자 (데이터를 공유하는 대상)

Cloudflare, Inc.(Workers / KV)는 당사를 대신해 가명 설치 식별자, 활성화된 경우 푸시 토큰, 플랫폼, 버전, 언어, 배포 채널, Premium 상태, 등록·활동 시각과 요청 IP를 처리합니다. 요청에는 닫은 공지 식별자와 해당 설치만을 위한 인증 정보가 포함될 수 있지만 압축 파일이나 비밀번호는 보내지 않습니다. Expo와 Apple / Google은 토큰, 알림 내용과 배달 메타데이터를 처리합니다. Cloudflare는 전 세계 네트워크를 운영하며 미국 등 EEA 외부에서도 처리할 수 있습니다. EU 전용 처리 지역은 설정하지 않았습니다. 이전에는 Cloudflare Data Processing Addendum이 적용됩니다.

7. 국제 전송

위에 언급된 일부 수신자는 유럽 경제 지역 외부에 위치합니다(주로 미국). 데이터 전송이 발생하는 경우, 다음을 통해 보호됩니다.

  • 프레임워크에 따라 인증된 제공업체(Google LLC 포함)에 대한 유럽 위원회의 적정성 결정 (EU-US Data Privacy Framework);
  • 유럽 위원회에서 채택한 표준 계약 조항 (SCCs), 해당되는 경우 추가 보호 조치로 보완됨;
  • 수신자 자체의 공개된 전송 메커니즘(예: Apple의 구속력 있는 기업 개인정보 보호 약속).

관련 보호 조치 사본을 요청하려면 mail@macsiem.dev로 서면 문의하십시오.

8. 보존 기간

설정과 기록은 삭제하거나 앱 데이터를 제거할 때까지 기기에 남습니다. 내보낸 파일은 선택한 위치에 남습니다. 설치 인증 정보는 보안 저장소에서 제거할 때까지 보관하며 iOS에서는 앱 삭제 후에도 남을 수 있습니다.

Unity 데이터는 해당 정책에 따라 보관합니다. Sentry 이벤트는 프로젝트 설정에 따라 보관 후 삭제합니다. 보고서에 적용되는 기간은 문의해 주세요. Cloudflare 등록·활동 기록은 등록 해제 또는 삭제 요청 처리까지 보관하며 현재 자동 만료는 설정되어 있지 않습니다.

지원 서신은 요청 해결과 필요한 후속 조치 또는 법적 의무를 위해 보관합니다. 로컬 구매 권한은 구매 확인 시 갱신되고 앱 데이터와 함께 제거됩니다. Apple / Google은 각 정책에 따라 거래 기록을 보관합니다.

9. 사용자의 권리 (GDPR Art. 15–22)

사용자는 개인 데이터와 관련하여 다음과 같은 권리를 가집니다.

  • 접근권 (Art. 15) — 당사가 사용자 데이터를 처리하는지 확인하고 해당 데이터 사본을 받을 권리. 대부분의 사용자 데이터는 이미 기기에 있습니다. 앱에서 내보내거나 나머지 데이터에 대해 당사에 문의하십시오.
  • 정정권 (Art. 16) — 부정확한 데이터를 수정할 권리. 앱에서 직접 데이터를 편집하십시오.
  • 삭제권(GDPR 제17조): 기록 화면에서 작업을, 시스템 파일 관리자에서 파일을 삭제할 수 있습니다. 당사나 제공업체가 가진 데이터는 문의해 주세요. 앱 삭제로 내보낸 파일이나 원격 기록이 삭제되지는 않습니다.
  • 처리 제한권 (Art. 18) — 일시적인 처리 중지를 요청할 권리. 당사에 문의하십시오.
  • 데이터 이동권(GDPR 제20조): 해당 권리가 적용되는 경우 당사가 보유한 개인 데이터 사본을 요청할 수 있습니다. 압축 파일은 시스템 선택기를 통해 저장하거나 공유할 수 있습니다.
  • 이의 제기권 (Art. 21) — 정당한 이익에 기반한 처리, 특히 프로파일링 방식의 광고에 이의를 제기할 권리. 앱 설정 또는 시스템 제어를 통해 개인 맞춤 광고를 비활성화하십시오.
  • 자동화된 결정에 대한 거부권 (Art. 22) — Archivr는 사용자에게 법적 또는 유사하게 중대한 영향을 미치는 자동화된 결정을 내리지 않습니다.

권리 행사는 mail@macsiem.dev로 요청하세요. 한 달 이내 답변합니다. 복잡성이나 요청 건수로 두 달 더 필요하면 첫 달 이내에 연장 이유를 알려드립니다.

당사가 사용자 데이터를 불법적으로 처리한다고 생각하는 경우, 감독 기관에 불만을 제기할 수 있습니다. 폴란드 거주자의 경우:

Prezes Urzędu Ochrony Danych Osobowych (PUODO) ul. Stanisława Moniuszki 1A, 00-014 Warszawa, Poland https://uodo.gov.pl

또한 사용자의 상거소, 직장 또는 주장된 침해 장소가 있는 다른 EEA 국가의 감독 기관에 불만을 제기할 수도 있습니다.

11. 아동의 개인정보 보호

Archivr는 일반 유틸리티이며 어린이를 위해 특별히 설계되지 않았습니다. 법률상 필요한 동의 없이 어린이의 데이터가 처리되었다고 생각되면 mail@macsiem.dev로 연락하세요. 조사 후 필요한 삭제 등 적절한 조치를 취합니다.

12. 보안

압축 작업은 메모리와 임시 또는 출력 파일을 이용해 기기에서 수행합니다. 비밀번호는 입력·처리 중 일시적으로 사용하고 설정, 보안 저장소나 기록에 저장하지 않으며 진단에서 비밀번호 필드를 필터링합니다. 광고, 구매, 진단과 Cloudflare 공지 통신은 HTTPS를 사용합니다. 데이터를 명시한 목적에 필요한 범위로 제한합니다. 완벽히 안전한 시스템은 없으므로 기기를 최신 상태로 유지하고 안전한 잠금을 사용하세요.

13. App Tracking Transparency (iOS) 및 광고 ID

iOS에서는 Unity Ads이 추적 등급 식별자를 사용하기 전에 Archivr는 시스템 App Tracking Transparency 동의 요청을 표시합니다. 사용자가 거부하는 경우, Archivr는 비개인 맞춤 광고만 제공합니다.

Android 설정 → Google → 광고에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 삭제되는 것은 해당 광고 식별자이며, 모든 SDK 식별자나 기술 처리가 중단되는 것은 아닙니다. 제한된 광고가 계속 표시될 수 있습니다.

14. 인앱 구매

Archivr는 Apple App Store 및 Google Play를 통해 평생 잠금 해제, 프리미엄 연간 구독, 선택적 팁 등 다음 인앱 제품을 제공합니다.

결제와 계정 정보는 Apple / Google이 처리합니다. Archivr는 카드 정보를 요구하지 않으며 반환된 구매·권한 정보를 사용하고 상태와 만료일을 로컬에 저장합니다. 구독은 iOS 설정 → Apple ID → 구독 또는 Google Play → 정기 결제에서 취소할 수 있습니다. 각 스토어 취소 규칙이 적용됩니다.

15. 본 정책의 변경
